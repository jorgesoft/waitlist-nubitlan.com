🧪 Responsive Design Testing Checklist

Instructions: Open the application at http://localhost:5174/evaluacion and test the following scenarios.

📱 Mobile Testing (320px - 767px)

Test breakpoints: 320px 375px 414px 767px

  • Touch targets are at least 44px (buttons, answer options)
  • Quiz answer buttons are at least 56px tall
  • Text is readable without horizontal scrolling
  • Card padding is reduced appropriately (1.25rem)
  • Buttons stack vertically in narrow viewports
  • Progress bar is visible and 10px tall
  • Icons don't cause layout issues
  • Footer items stack vertically
  • Navbar brand and buttons fit properly
  • All content is accessible without zooming

📱 Small Mobile (320px - 479px)

Test breakpoint: 320px

  • Container padding is 1rem on each side
  • Button text size is readable (0.95rem)
  • Large icons are scaled down appropriately
  • Outcome card header padding is optimized
  • No horizontal overflow occurs

💻 Tablet Testing (768px - 1023px)

Test breakpoints: 768px 1023px

  • Touch targets are at least 42px for buttons
  • Quiz answer buttons are at least 52px tall
  • Container max-width is 720px
  • Card body padding is 2rem
  • Layout uses available space efficiently
  • Buttons can be side-by-side where appropriate

🖥️ Desktop Testing (1024px+)

Test breakpoints: 1024px 1440px 1920px

  • Text paragraphs have optimal line length (max 65ch)
  • Hover effects work smoothly (8px transform)
  • Layout is centered and not too wide
  • All interactive elements are easily clickable

🔍 Zoom Testing (200%)

Set browser zoom to 200% and test at various viewport sizes

  • No horizontal scrolling occurs
  • Text wraps properly in buttons
  • Flex items wrap when needed
  • Container doesn't cause overflow
  • All content remains accessible
  • Touch targets remain adequate

📐 Landscape Mobile Testing

Test mobile devices in landscape orientation

  • Vertical padding is reduced appropriately
  • Content fits without excessive scrolling
  • Card spacing is optimized
  • Quiz remains usable in landscape

⌨️ Additional Checks

  • Keyboard navigation works at all breakpoints
  • Focus indicators are visible on all screen sizes
  • Color contrast meets WCAG AA at all sizes
  • Touch targets don't overlap
  • Text remains readable at all zoom levels
Testing Tools:
  • Chrome DevTools: F12 → Toggle Device Toolbar (Ctrl+Shift+M)
  • Firefox: F12 → Responsive Design Mode (Ctrl+Shift+M)
  • Browser Zoom: Ctrl/Cmd + Plus/Minus
  • Test on real devices if available
